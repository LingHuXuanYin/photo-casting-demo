# 模特卡片生成器 · 用户手册

> 一款专为模特群体打造的极简模卡工具
> 本地部署 · 零账号 · 零云依赖 · 30 秒出图

---

## 📖 这是什么

模特卡片（Model Card）是模特对外展示的"作品"，包含：
- 个人照片（主图 + 辅图）
- 身体数据（身高/体重/三围/鞋码）
- 联系方式
- 品牌感强的排版

**模特卡片生成器**帮你快速做出专业级的模卡 JPG / PDF 文件，可直接用于：
- 📱 微信 / 微博 / 小红书 分享
- 📧 投递给经纪公司 / 品牌方
- 🖨 打印放进 Portfolio 作品集

设计稿：`docs/模特卡片生成器-产品原型设计.md`
迭代进度：`docs/迭代开发报告-v0.1.md` ~ `v0.4.md`

## 🛠 安装

### 前置条件

- **Node.js 18.18+** （LTS 版本即可）
  - 下载：<https://nodejs.org/>
  - 验证：终端输入 `node -v`，看到 `v18.18` 或更高即可
- **约 1 GB 磁盘空间** （含 32 MB 字体 + 200+ MB npm 依赖）
- **现代浏览器**：Chrome / Edge / Firefox / Safari 最新版

### 安装步骤

```powershell
# 1. 进入项目目录
cd C:\Users\eva\Documents\photo-design

# 2. 安装所有依赖
npm install

# 3. 字体文件检查（应该已经在 server/fonts/ 里）
#    4 个文件：Inter-Regular.ttf, Inter-Bold.ttf, SourceHanSansSC-Regular.otf, SourceHanSansSC-Bold.otf
#    如果丢失了，重新下载：
#       node scripts/download-fonts.js   # 思源黑体 ~32MB
#       node scripts/download-inter.js   # Inter 拉丁 ~120KB

# 4. 启动开发服务
npm run dev
```

启动后会自动打开两个服务：
- 🌐 **前端**（用户界面）：<http://localhost:5173>
- ⚙️ **后端**（渲染 API）：<http://localhost:3001>

打开浏览器访问 <http://localhost:5173> 开始使用。

> 💡 **首次启动如果浏览器显示"加载项目…"卡住**，检查后端是否正常启动（终端日志），或访问 <http://localhost:3001/api/ping> 看到 `pong from model-card-server` 即正常。

## 🚀 3 步出第一张模卡

### 第 1 步：新建项目

打开 <http://localhost:5173>，看到 Dashboard（项目列表）。

- 首次使用：会看到空状态"📷 还没有任何项目"，点 [+ 新建第一个项目]
- 老用户：点右上角 [+ 新建项目]

进入画布编辑器。

### 第 2 步：选模板 + 填资料

1. **点工具栏 [📐 模板]** 按钮 → 弹出 5 个内置模板
2. **选一个模板**（比如"黑白大片"），点 [应用模板]
3. **点 [👤 模特信息]** 工具栏按钮 → 填你的姓名 / 身高 / 体重 / 三围 / 鞋码
4. 画布上的文字会自动同步你填的内容（无需手动改）
5. **双击画布上的图片占位**（虚线框"双击上传照片"）→ 选择你的照片

### 第 3 步：导出

1. 工具栏点 [🚀 导出]
2. 选 JPG 或 PDF + 1x（屏幕）或 2x（高清）
3. 点 [🚀 导出] → 文件自动下载
4. 回到 Dashboard 看项目卡是否带缩略图（自动生成）

完成！把这个文件发给经纪公司 / 品牌方吧。

## 🖱 画布编辑器完整使用

### 画布尺寸切换
- 工具栏右边 [画布: A4 竖版 ▼] 下拉选预设
- 选 [自定义] 可输入任意像素尺寸

### 元素操作
| 操作 | 快捷键 / 鼠标 |
|------|------|
| 选中单个元素 | 鼠标左键点元素 |
| 多选 | 按住 Shift + 鼠标左键点；或鼠标框选 |
| 移动 | 鼠标拖拽元素 |
| 缩放 | 拖拽元素四周的小方块 |
| 旋转 | 拖拽元素上方的小圆点 |
| 删除 | Delete 键 / 右键菜单 |
| 复制 | Ctrl+D / Cmd+D |
| 撤销 | Ctrl+Z / Cmd+Z |
| 重做 | Ctrl+Y / Cmd+Shift+Z |
| 多选对齐 | 选中多个后，图层面板会出现对齐按钮 |
| 吸附栅格 | 工具栏 [▦] 切换（默认 8pt 栅格） |
| 辅助线 | 工具栏 [:] 切换（默认开启） |

### 文字编辑
- **双击文字** 进入编辑模式
- 选中文字 → **右侧属性面板** 可改：内容 / 字号 / 字体 / 颜色 / 对齐 / 粗体斜体
- 模特信息会自动同步：填一次资料，画布上所有相关文本实时变

### 图片替换
- 模板里的图片是**占位**（白底+虚线框+"双击上传照片"）
- **双击占位图** → 选你的照片
- 或 选中占位图 → 右侧属性面板 [📷 选择图片替换] 按钮
- 上传后保持原位置/尺寸，鼠标可继续调整

### 等比例缩放
- 选中图片 → 右侧"宽高比"区段
- 8 种预设：1:1 / 3:4 / 2:3 / 5:7 / 9:16 / 4:3 / 3:2 / 16:9
- 点预设 → 按当前宽度等比算高度
- [🔒 锁定] 后改宽/高自动联动算另一个

### 手动保存
- **Ctrl+S** / **Cmd+S** 立即保存（不等 2s 防抖）
- 右下角状态指示器：
  - ⚪ 空闲
  - 🔄 保存中…
  - ✅ 已保存 hh:mm
  - ❌ 保存失败

### 图层管理
- 左侧 [图层] 面板：所有元素列表
- 拖拽调整顺序 / 点 [置顶]/[置底]/[上移]/[下移] 按钮
- 点眼睛图标切换显隐
- 点锁图标切换锁定（锁定后不可选中编辑）

## 📂 Dashboard（项目列表）

点工具栏左侧 [← 我的项目] 回到 Dashboard。

### 功能
- **搜索**：按项目名 / 模特名 / 英文名实时过滤

### 排序
- 项目按 `更新时间` 倒序（最近改动的在最上面）

## 📤 导出格式

| 格式 | 适合 | 分辨率选项 |
|------|------|------|

## ❓ FAQ

### Q1：能换字体吗？
A：v1 阶段**思源黑体 + Inter** 是固定打包的（OFL 免费可商用）。后续 v2 会支持自定义字体。

### Q2：图片会被压缩吗？
A：上传到画布后保持原始分辨率。导出时按选择的 scale 渲染（1x = 原画布尺寸，2x = 翻倍）。

### Q3：项目存在哪？
A：浏览器本地 IndexedDB（数据库名 `model-card-db`）。**清除浏览器数据 = 项目全丢**。建议重要项目导出后存到网盘备份。

### Q4：能多设备同步吗？
A：v1 暂不支持（纯本地）。v2 会上账号体系 + 云同步。

### Q5：能导 CMYK 印刷色彩吗？
A：v1 导出的都是 RGB。印刷需要 CMYK 转换（如 Photoshop / Illustrator 转），PDF 也是 RGB 内嵌图。

### Q6：能直接打印吗？
A：可以。PDF 2x 高清 适合 A4 打印。色彩以打印机 / 屏幕为准（无 ICC 配置）。

### Q7：能加自定义模板吗？
A：v1 仅内置 5 个模板。v2 会加"另存为模板"功能。

### Q8：导出文件存在哪？
A：默认下载到浏览器下载目录（如 `C:\Users\<你>\Downloads\`）。

### Q9：能批量导出多个项目吗？
A：v1 暂不支持。v2 可考虑。

### Q10：能分享项目给他人编辑吗？
A：v1 暂不支持。v2 会加项目导出/导入（JSON 格式）。

## 🔧 故障排除

### 启动后浏览器显示"加载项目…"卡住
- 检查后端是否启动：终端应看到 `[fonts] 已注册 4 个字体 family` 和 `🚀 Server ready at http://localhost:3001`
- 访问 <http://localhost:3001/api/ping> 看到 `pong from model-card-server` 即可
- 如果 3001 端口被占用，停掉占用进程（Windows: `netstat -ano | findstr :3001` 找 PID 然后 `taskkill /PID <pid> /F`）

### 导出图片中文显示为方框 □
- 检查 `server/fonts/` 目录是否有 4 个字体文件
- 如果丢失，运行 `node scripts/download-fonts.js` 和 `node scripts/download-inter.js` 重新下载
- 重启 dev server（`npm run dev`）

### 浏览器报"无法连接到 localhost:3001"
- 后端没起来。终端看启动日志有没有报错
- 常见错：端口被占用、字体文件丢失、Node.js 版本过低

### Dashboard 没显示 / 显示空状态但明明有项目
- 硬刷新：`Ctrl + Shift + R`（Win）/ `Cmd + Shift + R`（Mac）
- 浏览器 DevTools → Application → Storage → Clear site data → 刷新
- 或换隐身模式 / 另一个浏览器

### 上传图片后没显示
- 检查图片格式：JPG / PNG / WebP
- 检查图片大小：浏览器对单张图 base64 编码有内存限制，< 20 MB 较稳

### 自动保存失败
- 右下角状态 [❌ 保存失败]
- 打开 DevTools Console 看具体错误
- 通常是 IndexedDB 写满（项目太多 / 图片太大）
- 解决：删几个项目 / 压缩图片

### Vite 启动报 `EADDRINUSE`
- 之前的 dev server 进程没清干净
- Windows: 打开 PowerShell 跑 `scripts\check-ports.ps1` 自动清

## 📁 数据存放位置

| 数据 | 位置 | 备份建议 |
|------|------|----------|
| 项目元数据 + 画布 JSON | 浏览器 IndexedDB `model-card-db` | 定期导出 / 截图保存 |
| 项目图片（base64） | 浏览器 IndexedDB `model-card-db` | 同上 |
| 缩略图 | 浏览器 IndexedDB `model-card-db` | 同上 |
| 当前打开的项目 ID | 浏览器 localStorage | 无需备份 |
| 字体文件 | `server/fonts/` | 仓库 git 里有，无需单独备份 |
| 导出的模卡 | 浏览器下载目录 | 自己存到云盘 |
