### 3.2 P0-4 模板系统

5 个内置模板，每个是完整画布 JSON：

| # | 模板 | 画布 | 布局 |
|---|------|------|------|
| 1 | 📇 经典竖版 | A4 595×842 | 上方主图 + 下方 3 辅图 + 模特信息 |
| 2 | 🌄 现代横版 | A4 842×595 | 左侧大图 + 右侧双图 + 姓名 |
| 3 | ◾ 极简方形 | 800×800 | 整图 + 底部 3 行信息 |
| 4 | 📸 大片风格 | A4 595×842 黑底 | 上方主图 + 中部双图 + 底部品牌风文字 |

**模板特性：**
- 每个模板有 1-5 个图片占位（用白底+虚线框+居中"双击上传照片"图表示）
- 应用模板时自动生成所有占位图的 dataURL
- 应用时记录历史点（可撤销回原状态）
- 应用后所有 linkedField 文本自动用当前 model 内容填充

### 3.3 8 项交互优化

#### 优化 #1：图片占位双击上传
- 模板占位是 Image 元素（带 `isPlaceholder: true` 标记）
- **画布上双击占位图** → 打开文件选择器 → 选图 → 自动替换
- 右侧属性面板对占位图也显示"📷 选择图片替换"按钮（紫色高亮）

#### 优化 #2-3：模特信息 linkedField 自动同步
- `TextElement` 新增 `linkedField` 字段，支持 8 个值：
  - `name` / `englishName` / `height` / `weight` / `bwh` / `shoe` / `stats` / `contact`
- 模板里模特姓名/身高/三围/鞋码等文本元素都设了 `linkedField`
- `setModel` mutator 改写：每次更新 model，**自动重算所有 linkedField 文本的 content**
- 用户体验：填一次模特信息，画布上所有相关文本实时同步，无需手动改每条

#### 优化 #4：图片宽高可输入数值
- 选中图片 → 右侧属性面板的"位置 / 尺寸"段
- "宽 / 高"两个 number input（带 `pt` 单位）
- 直接改数字就生效（按 Enter 或失焦）
- 改完记录历史点（可撤销）

#### 优化 #5：等比例缩放（aspect ratio）
- 选中图片 → 右侧属性面板新加"宽高比"段
- 8 个预设按钮：`1:1 / 3:4 / 2:3 / 5:7 / 9:16 / 4:3 / 3:2 / 16:9`
- 点击 → 图片按比例调整（按 w 等比缩 h）
- 锁定后改"宽/高"自动联动算另一个
- 显示"🔒 已锁定 3:4"提示
- "🔓 解锁"按钮恢复自由缩放
- 显示"当前: 0.667 : 1"实时反馈

#### 优化 #6：占位改用生成图片
- 之前：Rect 灰底 + 上面叠一个"📷 双击上传 X"文字 = 2 个元素
- 现在：**1 个 Image 元素** = 浏览器 canvas 实时生成白底+虚线框+居中文字"双击上传照片"
- 应用模板时调 `generatePlaceholderDataURL(w, h, "双击上传照片")` 生成
- 文字在 `placeholderImage.ts` 统一定义（要改文案只改一处）

#### 优化 #7：新增"黑白大片"模板
- 用户提供参考图：左黑右白 1600×800 布局
- 完整复刻：左 22% 黑信息栏（姓名 + 4 行中英双语 stats）+ 中 30% 全身 + 右 48% 2×2 头像
- 用到 4 个新 linkedField：`height / weight / bwh / shoe`（独立值）
- 中英双语：labels 静态（"身高 height"），values 走 linkedField

#### 优化 #8：黑白大片信息栏背景改全画布
- 之前：黑色 RECT 350×800（只覆盖左 22%）
- 现在：**底层黑色 RECT 1600×800**（覆盖全画布） + 上层白色 RECT 1250×800（覆盖右侧 78%）
- 视觉无变化，但底层色块是全画布大小，可以单独换底层色或加渐变/纹理

## 七、关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 持久化 | IndexedDB（不上云） | 本地单机部署，零依赖；图片也存 base64 |
| 自动保存策略 | 2s 防抖 + 序列化对比 | 用户连续操作不频繁写盘；空操作（pushHistory 等）不触发保存 |
| 模板占位 | Image 元素 + isPlaceholder 标记 | 不用 Rect+Text 组合占位，单一元素，结构干净；上传后原地转真图 |
| 模特信息同步 | linkedField 字段 + getModelLinkedText 辅助 | 模板里文本元素标记 linkedField；store setModel 时自动重算内容 |
| 宽高比 | 状态提升到 PropertiesPanel 顶层 | CommonFields 通过 onWidthChange/onHeightChange 回调协调，比例和输入框解耦 |
| 状态显示 | 右下角紧凑指示器 | 不打断用户视线，但能随时看到保存状态 |
| 模板应用 | fillPlaceholders 在 apply 时生成占位图 | dataURL 与画布尺寸对应，模板定义保持数据纯净 |
| 多 projectId 来源 | localStorage 存当前 ID + IndexedDB 存数据 | 不需要账号体系的前提下，刷新能恢复工作状态 |

## 九、待优化 / 已知限制

1. **历史记录粒度**：仍是全量快照，每次保存整个 elements 数组。10 步后约 10 倍内存。后续可改 patch-based 增量
2. **图片存储大小**：base64 编码 +33%，5MB 图 ≈ 6.7MB base64。IndexedDB 5MB 单项限制？实际是 50MB-1GB 取决于浏览器，但大图仍会卡。可后续加 sharp 压缩
3. **文字高度自动调整**：el.h 不会因 fontSize/lineCount 变化自动重算（依赖 visualHeight 兜底）
4. **模特信息同步触发保存**：每次 setModel 改画布会触发 auto-save。频繁输入可能多次写盘（但有 2s 防抖缓解）
5. **等比例锁定的多选行为**：当前只对单选图片生效，多选时不会按比例联动
6. **模板占位的 placeholder 文字不可配置**：写死在 `generatePlaceholderDataURL` 里，要改文案要改代码
